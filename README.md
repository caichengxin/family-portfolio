# Family Portfolio V1.3A — Personal Market Data

Deploy the root files to the existing GitHub Pages repository. Requires existing 01/02 SQL and deployed `market-quotes` Edge Function from 03. No SQL change, no function replacement, no new secrets. Preserve the existing authentication settings.

- The original administrator can request Alpaca IEX latest trades only for their own accounts. This is a personal connectivity/valuation test, not a shared-family quote service. Quotes are stored only in memory for the current page/session, cleared on sign-out, and not written to `stock_prices`, holdings, localStorage, notifications or snapshots. The original server-side restriction remains authoritative.
- Selecting a verified ticker requests its price. Existing personal positions fetch on login, refresh and approximately every 15 minutes while the app is visible. Requests batch up to 25 symbols, deduplicate, and keep a minimum 60-second retry/manual-refresh interval per symbol. Last valid quotes survive failures during the same page session. The latest trade may be older than the fetch time. IEX is not a consolidated all-exchange feed.
- Automatic market quotes take priority over stored references for the administrator’s own holdings. Other members’ accounts do not use these quotes. Manual and screenshot references are preserved as fallbacks. Cash unknown is never substituted with buying power; partial totals stay labelled. Reported snapshots remain separate.
- Before deployment, confirm the anonymous rejection test returns 401/403 and rotate any exposed Alpaca credentials. Use test data until cross-member authorization tests pass. No shared quote display, daily snapshot cron, full market ticker search, buy plans, email or push added in this release. Provider permission is required before enabling shared family quote access.
